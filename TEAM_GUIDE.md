## What Did We Build?

POLARIS (Polar Research & Information System) is a unified web platform that brings ALL of Indias polar research knowledge into one place.

Analogy: Imagine India has done 44+ polar expeditions, but information is scattered across different websites, PDFs, and databases. POLARIS is like creating ONE platform that has EVERYTHING about polar research.

### What POLARIS Has:

| Feature | What It Does |
|---------|-------------|
| Homepage | Shows live stats (11 expeditions, 8 publications, etc.), search bar |
| Expeditions | Browse all Indian polar expeditions with details |
| Publications | Scientific papers and research publications |
| Datasets | Scientific data from expeditions |
| Gallery | Photos and YouTube videos from expeditions |
| Map | Interactive map showing polar stations (Bharati, Maitri, Himadri) |
| Education | Simplified polar science for students |
| Search | Search across everything at once |
| Outreach Studio | Admin tool that auto-creates social media posts |
| Admin Dashboard | For staff to manage all content |
| Credits | Team info and photos |
| 404 Page | Fun Lost in Polar Region page for wrong URLs |

### The KEY Concept - Connected Knowledge

Normal website: Each document is separate. You open a PDF, thats it.

POLARIS: Everything is CONNECTED.

Open an Expedition -> See Reports -> Publications -> Datasets -> Photos -> Videos -> Map

ONE expedition = ALL related resources in one place.

This is what makes us special.

## Judge Q&A - Easy Answers

### Technical Questions:

Q: What tech stack did you use?
A: React for frontend, Express.js for backend, PostgreSQL for database, deployed free on Vercel and Railway.

Q: How does Connected Knowledge work?
A: Every resource (report, publication, dataset, photo) links back to its expedition. Open one expedition, see ALL related resources.

Q: How does Outreach Studio work?
A: Admin selects an expedition, picks a template (social post, newsletter, article), and the system generates verified content from database. No fake facts.

Q: Can this handle real NCPOR data?
A: Yes. Schema designed for easy CSV/Excel import. We have 80+ demo entries based on real NCPOR facts.

### Non-Technical Questions:

Q: How is this different from the NCPOR website?
A: NCPOR website has scattered content. POLARIS connects everything. One expedition page shows ALL related reports, publications, datasets, photos, and map locations.

Q: What is the biggest challenge?
A: Getting real NCPOR data integrated. Our solution: schema designed for easy import from CSV/Excel.

Q: How does this benefit students?
A: Education Hub provides simplified polar science content. Students can explore expeditions, see photos, watch videos without reading technical documents.

Q: What about scalability?
A: Free tier handles moderate traffic. Architecture scales to paid hosting when needed. PostgreSQL is enterprise-grade.

Q: Did you use AI?
A: For MVP, we use template-based content generation. AI can be added later for semantic search and smarter content.
